### Featured work

**AI agents and LLM systems**

| Project | What it does |
| --- | --- |
| [spec-assistant-3gpp](https://github.com/JafarBanar/spec-assistant-3gpp) | Citation-grounded RAG over 3GPP NR specifications. Every factual sentence carries a clause citation, or the system refuses to answer. From-scratch BM25, programmatic citation validation, MRR 0.957 on a labelled eval set. |
